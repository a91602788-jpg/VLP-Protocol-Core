# Сообщения о проблемах безопасности

Для `a91602788-jpg/VLP-Protocol-Core` сообщать об уязвимости приватно уполномоченному сопровождающему
проекта. Если в GitHub доступна функция **Security → Report a vulnerability**,
можно использовать её. Иначе воспользоваться уже согласованным закрытым каналом
команды; публичный issue для чувствительных деталей не подходит.

В сообщении указать затронутую версию или commit, сценарий воспроизведения,
ожидаемое и фактическое поведение, возможное влияние. Приложить минимальный
пример на синтетических данных без ключей, токенов и персональных данных.

Срок поддержки версий и срок ответа этим документом не устанавливаются.
Проверять состояние исправления по принятому изменению и заметкам выпуска.
Правила безопасности и эксплуатационные ограничения проекта сохраняют приоритет.
